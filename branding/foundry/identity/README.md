# AK Engine / Foundry identity

Original AK Studio vector paths. The ivory monogram is cut from simple geometric forms; the detached copper key is the only accent and carries through into the editor and motion ident. The lockup uses custom vector lettering and needs no fonts. Designed for a graphite background; the SVG has no background. Scale the monogram separately at icon sizes.

Identity artwork is provided under MIT with the AK Engine repository copyright notice. No borrowed marks, raster sources, or font files.
