# AK Engine Foundry redesign

This is a standalone review preview, not a change to the AK runtime, the upstream editor fork, or the existing startup flow.

- [Identity](identity/README.md): original vector mark, custom wordmark, and palette.
- [Workbench](ui/README.md): native Godot prototype with a real 3D sample scene and working inspection tools.
